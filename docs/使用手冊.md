# 使用手冊

## 1. 開始前

1. 安裝套件：`pip install pymupdf opencv-python-headless numpy`
2. 準備規格書 PDF，找到含「Recommended PCB layout」（建議焊盤圖）的那一頁。
3. 先弄清楚圖上有哪些資料：
   - 每個焊盤的編號（#1、#2…）
   - 兩個焊盤之間一段**標有距離**的尺寸（用來校準比例）
   - 其他焊盤間的標註（用來驗證）
   - 焊盤與鑽孔尺寸（例如 `6-1.00`、`6-0.60`、`5-1.60`）。注意個別焊盤可能和其他不同。

> 圖面不一定是 1:1，程式不假設比例，一律靠你輸入的已知距離校準。

---

## 2. 圖形介面（footprint_wizard.py）

啟動：
```
python footprint_wizard.py
```
視窗左邊是 PDF 或裁切圖，右邊是步驟與控制項，右下角是 footprint 即時預覽。上方步驟列會標示目前步驟。

### 步驟 1：開啟 PDF
按「開啟 PDF」，選檔。可用頁碼欄切換頁面。開啟後自動進入下一步。

### 步驟 2：框選區域
- 紅框是程式自動找到的建議焊盤圖範圍。
- 位置不對時，在圖上拖曳重新框選，範圍只要包住焊盤圖即可。
- 可用「放大 +／縮小 −」調整顯示，「重新自動尋找」會重新偵測。
- 按「下一步」。

### 步驟 3：確認焊盤
- 每個焊盤上應有一個紅點與綠框。
- 多了：在該焊盤上**按右鍵**刪除。
- 漏了：在焊盤中央**按左鍵**新增。
- 「焊盤數量」填 0 代表自動；知道確切數量時可填入再按「重新偵測」。

### 步驟 4：標示 Pin 編號
- 在右側輸入框填入目前要指派的編號（預設 1）。
- 依規格書圖上的編號，在圖上逐一點擊對應焊盤。每點一次，數字自動加 1。
- 編號順序與圖上不同時，每次點之前先改輸入框。
- 右鍵可清除該焊盤的編號；「全部清除」重來。
- 編號不得重複，且每個焊盤都要有編號才能進入下一步。

### 步驟 5：校準比例
1. 在圖上點選兩個你知道實際距離的焊盤（選中會變橘色）。
2. 輸入圖上標註的距離（mm）。例：左右兩排 4.40 + 4.40 = 8.80。
3. 按「套用」，再按「下一步」。
4. 選錯了按「重選」。

選擇距離長、標註清楚的兩個焊盤，誤差會比較小。

### 步驟 6：驗證與匯出
- **原點**：可選「焊盤中心」或某個 Pin。
- **表格**：顯示每個 Pin 的座標與尺寸，雙擊儲存格可修改。鑽孔預設為「焊盤尺寸 − 0.4 mm」，**請對照圖面改成實際值**。鑽孔寬填 0 代表 SMD 焊盤。
- **用規格書標註值驗證**：
  1. 輸入 Pin A、Pin B、方向（X、Y 或距離）、圖上的標註值，按「加入」。
  2. 下方顯示 ✔（差距在 0.1 mm 內）或 ✘。
  3. 請盡量把圖上所有焊盤間的標註都加進來，**不要只加校準用的那一段**。
- **匯出**：填名稱，按「匯出 .kicad_mod + .csv」，兩個檔案存放在同一位置。

### 常見問題
| 狀況 | 處理 |
|---|---|
| 自動找不到區域 | 在圖上手動拖曳框選 |
| 焊盤沒被偵測到或位置歪 | 步驟 3 用右鍵／左鍵增刪；框選範圍縮小只含焊盤圖 |
| 驗證出現 ✘ | 檢查 Pin 編號、校準距離、標註值是否輸入錯，再重新校準 |
| 預覽沒有畫面 | 還沒完成校準 |

## 3. 命令列（measure.py）

腳本位置：`.github/skills/pdf-to-footprint/scripts/measure.py`。以下以 `measure.py` 簡稱。

### find：找區域
```
python measure.py find PDF --page 1
```
輸出 `x0,y0,x1,y1`（PDF 座標，單位 pt）。輸出 `not found` 時需自行決定區域。

### detect：偵測焊盤
```
python measure.py detect PDF --page 1 --region x0,y0,x1,y1 --out out
```
產生 `out/pads.json` 與 `out/overlay.png`。請開啟 overlay.png，確認每個焊盤都有標記、數量正確。圖上的數字是**偵測索引**，不是 Pin 編號；索引依左欄到右欄、由上到下排列。

### build：產生 footprint 並驗證
```
python measure.py build out\spec.json --out out
```
先寫好 `spec.json`：

```json
{
  "name": "DA2-4164R-60BMX-U",
  "pads_json": "pads.json",
  "pins": {"0": "4", "1": "6", "2": "5", "3": "3", "4": "2", "5": "1"},
  "calibration": {"a": "5", "b": "1", "distance_mm": 8.8},
  "origin": "6",
  "pad": {"default": [1.0, 1.6], "1": [1.0, 1.8]},
  "drill": {"default": [0.6, 1.2], "1": [0.6, 1.4]},
  "checks": [["5", "4", "Y", 8.45], ["5", "6", "Y", 2.5], ["2", "3", "Y", 3.0], ["1", "3", "Y", 8.8]]
}
```

| 欄位 | 說明 |
|---|---|
| `name` | footprint 名稱，也是輸出檔名 |
| `pads_json` | detect 產生的檔案，路徑相對於 spec 所在位置 |
| `pins` | 偵測索引 → Pin 編號 |
| `calibration` | 兩個 Pin 與它們的實際距離（mm） |
| `origin` | `"center"` 或某個 Pin 編號 |
| `pad` / `drill` | `[寬, 高]`（mm）。`default` 為預設值，個別 Pin 可覆寫。drill 填 `[0, 0]` 代表 SMD |
| `checks` | `[PinA, PinB, "X"｜"Y"｜"D", 圖上標註值]` |

`build` 會逐項比對，並檢查你填的焊盤尺寸是否和量到的外形相符（±0.15 mm）。全部通過結束碼為 0，任何一項失敗則為 1。失敗時請重新對照圖面修正 spec，不要放寬容許值或刪掉失敗的項目。

## 4. 透過 Copilot skill 使用

在此資料夾開啟對話，直接說：

> 幫我把 `DA2-4164R-60BMX-U.pdf` 的建議焊盤圖做成 KiCad footprint

或輸入 `/pdf-to-footprint`。流程為：LLM 看圖找出建議焊盤圖，執行 `find` 與 `detect`，檢查 overlay，讀圖寫出 `spec.json`，執行 `build` 驗證，最後回報通過的檢查與未驗證的項目。

## 5. 在 KiCad 裡使用輸出檔

1. 開啟 KiCad 的 **Footprint Editor**。
2. File → Open（或 Import → Footprint from File）選取 `.kicad_mod`。
3. 對照 PDF 檢查焊盤位置、尺寸與編號。
4. 要長期使用時，存進自己的 `.pretty` 資料夾，並在 Preferences → Manage Footprint Libraries 加入。

匯出檔不含本體外框、絲印、pin 1 標記、定位柱與 PCB 缺口，請依圖面自行補上。

---

## 6. 輸出格式

**.kicad_mod**：KiCad 8 格式，單位 mm，Y 軸向下。橢圓孔使用 `(drill oval 寬 高)`。

**.csv** 欄位：

| 欄位 | 意義 |
|---|---|
| pin | Pin 編號 |
| x_mm, y_mm | 焊盤中心座標 |
| pad_w_mm, pad_h_mm | 焊盤寬、高 |
| drill_w_mm, drill_h_mm | 鑽孔寬、高（0 代表無孔） |

座標已對齊 0.05 mm 格點。

## 7. 已知限制與注意事項

- 只在兩份規格書(DA2、A1241)上測過。偵測依賴「有斜線陰影的橢圓焊盤」(實心或空心外框皆可)。自動找區域可能選錯(例如把滾花紋當焊盤),此時請手動框選;框選要包含整排焊盤,盡量避開其他有斜線的圖形。若焊盤貼著尺寸線/PCB 邊線,最下或最上的焊盤高度可能偏短,請看疊圖並以標註尺寸檢查。
- 沒有 OCR，所有標註數字需人工或 LLM 讀圖後輸入。
- 驗證容許誤差是 0.1 mm；圖面公差更小時（例如 ±0.05），請自行加嚴判斷。
- 驗證只能確認「量到的位置」與「你輸入的標註值」一致，無法保證 Pin 編號、焊盤與鑽孔尺寸本身讀對。請務必目視比對 PDF。
- 輸出檔未在 KiCad 內開啟驗證。
- 不含 3D 模型。
